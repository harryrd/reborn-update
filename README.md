# reborn-update

Tempat unduhan exe klien Reborn (Windows) untuk updater otomatis.

- File exe ada di halaman [Releases](https://github.com/harryrd/reborn-update/releases).
- Klien mengecek versi terbaru lewat `https://reborn-update.pages.dev/version.json` dan memasang update sendiri.
- Repo ini tidak berisi source code atau aset game.
